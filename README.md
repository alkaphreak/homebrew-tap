# alkaphreak/homebrew-tap

Homebrew formulae for alkaphreak's tools. Formulae are published automatically by each
project's release CI; do not edit them by hand.

```bash
brew install alkaphreak/tap/taskwarrior-connector
```

| Formula                 | Project                                                                                   |
|-------------------------|-------------------------------------------------------------------------------------------|
| `taskwarrior-connector` | [Taskwarrior-Connector](https://github.com/alkaphreak/Taskwarrior-Connector) local daemon |
